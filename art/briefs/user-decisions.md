# 사용자 결정과 확인된 스타일 기준

아래는 대화에서 확인한 사용자 요청이다. 이미지 생성 도구에 전달한 전체 프롬프트의
대체본이 아니며, 원문 미복구 항목을 임의로 채우는 용도로 쓰지 않는다.

- “조용한 수집 동료 선택.”
- 도형 조합의 한계를 넘어, 누끼·외곽선을 고려한 새로운 고양이 캐릭터.
- 위트와 고양이의 습성을 살린 극장판 2D 애니메이션풍. 표현 디테일은 과하지 않게.
- “렉돌을 고양이를 롤모델로 엉뚱함과 귀여움을 스타일로 시안을 추가해줘”
- “솜뭉치 사냥꾼 선택”
- 악세사리를 폐기하고 실제 고양이 종류를 확대. 품종별 외형·성격·기본 자세·모션·표정 차별화.
- 처음부터 자유 선택하며 고양이별 개성을 유지.
- 다른 앱의 키·마우스 입력에는 반응하지 않고 고양이를 직접 클릭하면 교감.

이때 지정된 원본 파일은 `exec-8e27f8fc-9c19-4ec9-b511-b4ee9fa54880.png`다.
카탈로그에서 `appearance-british-original` → `appearance-british-tail-revision` →
`appearance-british-shorthair`로 보존한다. 실제 생성 호출의 상세 인자는 원문 미복구 상태다.

현재 12종의 고정 ID·외형·연기는 [캐릭터 사양](../../docs/specs/cat-companions.md)과
[직접 교감 설계](../../docs/superpowers/specs/2026-10-30-private-companionship-design.md)를 따른다.
턱시도는 품종이 아닌 털 무늬다. 역사적 악세사리 시안과 옛 통계·성장 아이디어는
현재 제품 요구로 복구하지 않는다.
