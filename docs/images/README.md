# README 실제 실행 이미지

이 폴더는 README에서 사용하는 **실제 앱 화면 캡처**를 보관합니다.
새 캐릭터 시안이나 합성한 UI가 아닙니다. 생성 원화·프롬프트는 별도의
[원화 보관소](../../art/README.md)를 참고하세요.

- 앱 소스: [`fcd64ba`](https://github.com/buildon99x/copy-pet/commit/fcd64ba673ab2a65b0e76267192c1d18a76cdef4)
- 촬영일: 2026-10-31
- 실행 환경: Linux X11 / Xvfb, 릴리스 바이너리, 한국어 UI, 기본 크기
- 고양이: 앱의 고양이 선택 화면에서 선택·적용한 뒤 해당 창 전체를 캡처
- 후처리: 없음. README의 HTML `width` 속성으로 표시 크기만 조절
- 개인정보: 별도의 테스트 설정 폴더와 합성 클립보드 내용 사용
