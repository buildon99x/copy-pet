# 02. Visual System — Dark Premium

## Visual keywords
Dark premium, warm mascot, productivity-grade clarity, soft glass, quiet glow, Korean/English-ready, compact density.

## Layout geometry
- Desktop pet canvas: 180–260 px logical width depending scale.
- Panel default canvas: 760×560 logical px in full app concept, compact runtime panel 360×542 canvas units.
- Runtime panel min/max: 280–600 × 220–700 canvas units.
- Panel opens around the anchored cat; cat screen position must remain stable while panel grows.

## Surfaces
- Window background transparent.
- Pet shadow: soft ellipse opacity 0.16–0.24.
- Panel surface: #181C24, radius 18–22.
- Panel stroke: white at 10–14% opacity.
- Selected row: subtle raised surface + gold border.
- Dangerous actions: red text/border only on armed/hover/confirm states.

## Typography
- Use OS UI font and Hangul fallback.
- Default body 13 px, title 16 px, small metadata 11 px.
- Monospace only for code preview.

## Icon style
- 1.5 px line icons, rounded caps, no heavy filled pictograms except source app badges.
- Source dots/badges are persistent identity markers.

## Tone
- Cat/fish are warm cream/red/gold.
- Productivity UI stays cool dark blue-gray.
- Gold is reserved for selection, XP, level, primary copy action.
