# 01. Product Contract

## 제품 정의
ClipCat은 클립보드 매니저를 데스크탑 펫 인터페이스로 표현한 Rust 데스크탑 앱이다. 사용자가 복사하면 물고기가 고양이에게 날아가고, 키보드/마우스 활동과 복사 이벤트는 XP/레벨/액세서리로 환산된다.

## 핵심 화면
1. 데스크탑 펫만 보이는 기본 상태.
2. 펫 위/옆에서 열리는 클립보드 패널.
3. Hover Stats Bubble.
4. Tray/context menu.
5. About/Settings는 최소 모달 또는 패널 내 섹션으로 처리.

## UX 원칙
- 사용자는 앱을 관리한다기보다 작은 고양이를 데스크탑에 둔다고 느껴야 한다.
- 패널은 강력하지만 과시하지 않는다. 기본은 작고 빠르고 조용하다.
- 모든 위험 동작은 되돌릴 수 있거나 확인 단계를 둔다.
- 검색/복사는 1초 안에 끝나야 한다.
- 한국어/영어는 런타임 전환 가능해야 하며 모든 라벨은 i18n 테이블에 있어야 한다.

## Non-negotiables
- 클립보드 텍스트는 로컬 저장만.
- 키 입력 내용은 읽지 않는다. 카운터와 핫키 비교만.
- 폰트는 OS 시스템 폰트 사용. 번들 폰트 금지.
- macOS/Windows 동작 차이는 숨기지 말고 UI에 명확히 반영한다.
