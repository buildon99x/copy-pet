# 입력 통계 없이 교감하는 ClipCat 개선안

2026-10-30 · 승인된 설계 · 기능 브랜치 구현 완료; OS별 실제 검증 범위는 작업 보고서 참조

## 목표와 확정 요구

사용자의 다른 작업을 관찰하는 인상을 줄이고, 사용자가 고양이에게 명시적으로
행동했을 때 고양이가 반응하는 동료로 정리한다.

- 모든 OS에서 키·클릭·스크롤 카운팅과 활동 시간 계산을 제거한다.
- 통계 화면을 비활성화하고 입력량에 따른 성장·보상도 중지한다.
- 고양이를 직접 클릭하면 품종에 맞는 모션으로 응답한다.
- macOS의 전역 패널 단축키를 `⌃⇧V`(Control+Shift+V)로 변경한다.
- 기존 12종 자유 선택, 클립 기록·태그·AI 프로젝트, Retina 가독성 수정을 유지한다.

사용자 확인으로 **레벨·XP 표시도 숨기는 방향이 확정**되었다.
숨은 집계를 계속하지 않도록 입력·복사·교감 기반 XP 계산과 레벨업 연출도 중단한다.
클릭 횟수나 교감 횟수는 집계하지 않는다. 기존 12종 자유 선택은 그대로 유지한다.

## 설계 승인 당시 코드에서 확인한 사실 (구현 전 기록)

| 위치 | 현재 동작 | 사각지대 |
| --- | --- | --- |
| `src/input.rs` | KEYS/CLICKS/WHEEL 원자 카운터와 누른 키 상태 | 화면만 숨겨도 카운팅은 계속될 수 있음 |
| `Pet::advance` | 키·클릭·스크롤 합산, 활동 분 단위 기록, 입력 XP | 카운터만 없애고 성장·활동 시간 경로가 남기 쉬움 |
| Windows backend | WH_KEYBOARD_LL/WH_MOUSE_LL 설치; 단축키는 이미 RegisterHotKey | 통계 제거 후 두 저수준 훅은 불필요 |
| macOS `mac_input.rs` | 전체 키·버튼·스크롤 이벤트 탭을 단축키에도 사용 | 카운팅 삭제만으로 입력 감시·권한 요구가 사라지지 않음 |
| Linux/Windows portable | rdev 전역 리스너로 카운팅·단축키 처리 | 특정 단축키 때문에 전체 입력을 듣는 구조 |
| `Pet::pet/click_bounce` | 현재 무반응 함수 | 예전 전체 입력 반응을 복구하지 않고 로컬 교감만 새로 설계해야 함 |
| `hotkey.rs`/Persist | 공통 win+shift+v 기본값을 macOS에서 Command로 표시 | 기본값만 바꾸면 기존 사용자의 저장된 단축키는 그대로 남음 |
| 실제 프레임 | 16개 중 복사·대기·깜빡임·수면 위주 | 복사 사냥 모션을 그대로 쓰다듬기로 쓰면 교감이 어색함 |
| macOS CI smoke | 수집·XP 카운터로 성공 일부 판정 | 통계 제거에 맞춰 실제 클립 저장 중심으로 검사를 바꿔야 함 |

## 접근 비교와 권장안

| 접근 | 효과와 비용 | 판단 |
| --- | --- | --- |
| 통계 UI만 끄기 | 빠르지만 입력 훅·계산·권한이 남음 | 보안 거부감 해소에 부족 |
| 카운팅 삭제 + 기존 전역 리스너를 단축키용으로 축소 | 집계는 중단하지만 전체 키 이벤트 수신은 남음 | 최종 목표로는 부족 |
| 카운팅 삭제 + OS 등록형 단축키 + 앱 창 안의 교감 이벤트 | 불필요한 감시와 권한을 줄이고 직접 교감은 유지; 플랫폼별 구현 필요 | **권장** |

권장안은 검토 제안이며 사용자가 이미 선택한 것으로 기록하지 않는다.

## 1. 통계·입력 수집 경로 정리

### 제거 범위

- 전역 키·클릭·스크롤 카운터, 자동 반복 카운팅용 키 상태, 활동 분 계산.
- 모든 XP/레벨 계산·레벨업 연출, 복사 횟수 통계, 통계 말풍선·메뉴·통계 초기화 메뉴·B 단축키.
- 통계 목적의 Windows 키보드/마우스 훅, macOS 이벤트 탭, portable 전역 리스너.
- 정보창·트레이 툴팁·설명서·권한 안내에 남은 입력량/통계 표현.
- 모션이나 교감을 위해 다른 앱의 타이핑·클릭·마우스 이동을 감시하는 경로.

통계 토글인 단독 B와 워크벤치 탐색용 Ctrl+B 등은 구분해, 통계와 무관한
앱 내부 명령을 함께 제거하지 않는다.

단순히 수치를 0으로 만들거나 UI만 숨기는 방식으로 완료 처리하지 않는다.
앱 창 안의 검색 입력·드래그·버튼·고양이 클릭은 기능 조작이므로 유지하되
횟수·내용·입력 패턴을 통계나 로그로 저장하지 않는다. 연타 제어용 짧은 메모리
상태는 화면 재생에만 사용하고 파일로 남기지 않는다.

### 전역 단축키의 대체 경로

| OS | 제안 | 확인할 한계 |
| --- | --- | --- |
| Windows 네이티브/portable | RegisterHotKey에 필요한 조합만 등록 | 충돌·등록 해제·재등록·폴백 표시 |
| macOS | Carbon RegisterEventHotKey 계열의 OS 단축키 등록 검증 | 현재 macOS/ARM·Intel에서 등록·충돌·생명주기 확인 |
| Linux X11 | XGrabKey 등 특정 조합 등록 | 레이아웃·CapsLock/NumLock 조합·충돌 |
| Wayland | 데스크톱이 지원하는 global shortcut 경로/portal 검토 | 기존 지원 범위를 과장하지 않음; 불가하면 명시적 대체 진입 제공 |

지원되지 않는 환경에서 전체 입력 리스너를 몰래 되살리는 폴백은 사용하지 않는다.
단축키 등록 실패 시 메뉴·가운데 클릭 등 대체 진입은 유지하고 상태를 설명한다.
Linux X11을 현재 지원 범위로 먼저 완성하고 Wayland 확장은 별도 작업으로 둔다.

`rdev::listen` 제거와 출력 전용 붙여넣기 시뮬레이션은 분리해 검토한다.
의존성 이름만 지우기보다 실제 감시 호출 경로가 없어졌는지 확인한다.

### 데이터와 설명

클립보드 내용·복사한 앱 이름·항목 생성 시각 등 기존 히스토리 기능에 필요한
로컬 정보는 유지한다. 따라서 “아무 데이터도 읽지 않는다”라고 안내하지 않는다.
“전체 키·마우스 사용량을 집계하지 않는다”와 클립보드 저장 범위를 구분한다.

이전 통계 필드는 로드 시 허용하되 새 집계에는 사용하지 않는다. 마이그레이션 제안은
다음 정상 저장부터 과거 통계/XP 필드만 직렬화에서 제외하는 것이다. 클립·태그·
프로젝트·선택한 고양이·기존 단축키 등 기능 데이터는 보존하고, 구형 설정을 읽은 뒤
정상 저장하기 전 원본을 덮어쓰지 않는다. 과거 통계의 정리와 클립/프로젝트 삭제는
반드시 분리한다. 구버전으로의 설정 다운그레이드 호환은 별도 보장하지 않는다.
통계 초기화 메뉴를 실수로 기록 전체 삭제에 재활용하지 않는다.

## 2. 직접 교감과 모션 확장

### 클릭 판정

- **고양이 실루엣 안에서 누르고, 드래그하지 않은 채 놓으면 교감**으로 판정한다.
- 누르는 순간 바로 재생해 드래그 시작을 쓰다듬기로 오인하지 않는다.
- 이동 임계값은 논리 포인트 기준으로 관리하고 1배/2배·고양이 크기 3단계에 적용한다.
- 패널·닫기·복사·크기 조절·상태 배지·투명 영역 조작은 교감으로 처리하지 않는다.
- 위치 잠금은 이동만 막으며 교감은 허용한다. 검색 중 교감이 포커스를 뺏지 않는다.
- 첫 단계는 단일 클릭을 기본으로 한다. 더블클릭의 별도 보상/동작은 추가하지 않아
  클릭 지연과 드래그 충돌을 줄인다.
- 고양이에 포커스가 있을 때 Enter/Space로 같은 반응을 주는 접근성 대체도 검토한다.
  패널 검색/항목 선택 키와는 분리한다.

투명 영역의 **무반응 판정**과 다른 앱으로의 **시스템 클릭 통과**는 다르다.
특히 macOS 창의 클릭 통과를 구현하려고 전역 마우스 감시를 새로 추가하지 않는다.

### 모션과 상태 규칙

- 기본 교감은 눈맞춤 → 품종별 몸짓 → 편안한 복귀의 0.6~1.2초 정도로 제안한다.
- 잠든 고양이는 직접 클릭 시 부드럽게 기상·응답한다. 기존 복사 반응은 유지하며
  일반 타이핑이나 다른 앱의 클릭으로 깨우지 않는다.
- 기본은 무음, 파티클은 최소화한다. 반복 클릭에 하트 폭발·자동 대사·알림을 쌓지 않는다.
- 연타는 짧은 반응을 병합하거나 다음 1개만 받아들이며 클릭 횟수를 저장하지 않는다.
- 표시 우선순위는 명시적 교감 > 복사 연출 > 자율 동작으로 제안한다. 진행 중 복사
  연출은 안전한 프레임에서 연결하고, 실제 클립 저장은 언제나 즉시 처리한다.
- 수집 일시정지 중에도 사용자가 클릭한 교감은 허용한다. 수집 정지 표시와 감정은 분리한다.
- 숨김·일시 중단에서는 재생/대기를 멈추고, 복원 후 연출을 몰아서 재생하지 않는다.
- 안정된 대기/수면은 정지 렌더링을 유지한다. 자율 그루밍·기지개는 후속 단계로
  두고, 도입하더라도 긴 간격·표시 중에만 제한한다. 동작 줄이기 옵션을 함께 검토한다.

### 품종별 교감 차별화 제안

실제 품종 전체의 성격을 단정하는 설명이 아닌 창작 캐릭터의 연기다.

| 고양이 | 직접 클릭했을 때의 대표 반응 |
| --- | --- |
| 랙돌 | 낮은 자세에서 고개를 기대며 느린 눈감음 |
| 버만 | 흰 앞발을 가지런히 모으고 고개를 살짝 기울임 |
| 샴 | 큰 귀부터 반응하고 긴 목을 내밀어 눈맞춤 |
| 봄베이 | 구리빛 눈을 느리게 깜빡이고 꼬리 끝을 작게 말음 |
| 라가머핀 | 두 앞발을 안쪽으로 모으며 포근하게 몸을 기댐 |
| 페르시안 | 반쯤 감은 눈으로 턱을 조금 들고 여유롭게 응답 |
| 터키시 앙고라 | 긴 목과 앞발을 우아하게 펴고 짧게 갸웃함 |
| 아메리칸 컬 | 뒤로 말린 귀를 유지하며 호기심 어린 고개 기울임 |
| 먼치킨 | 짧은 앞발로 작은 두 번의 답례 동작; 넘어짐 개그 없음 |
| 브리티시 쇼트헤어 | 둥근 눈을 천천히 감고 턱만 조금 움직이는 담담한 답례 |
| 러시안 블루 | 잠깐 바라본 뒤 작은 코 인사와 부드러운 눈감음 |
| 턱시도 무늬 | 흰 앞발로 볼을 살짝 가리거나 윙크한 뒤 태연하게 복귀 |

복사 사냥을 그대로 재사용하지 않고 교감 전용 포즈를 추가한다. 부위별 클릭
반응은 후속 검토로 두어, 첫 단계에서 머리·꼬리의 작은 클릭 영역을 강요하지 않는다.

### 성능 제약

현재 16프레임에 교감용 4~8포즈를 더해 캐릭터당 최대24프레임을 시작 예산으로
삼는다. 240×180 RGBA 24장은4,147,200바이트로4MiB 미만이다. 선택한 한 마리만
상세 캐시를 소유하며 12종을 동시에 해독하지 않는다. 24프레임을 넘기려면 실제
메모리·전환 비용을 측정하고 자산 구성을 다시 결정한다. 모션별 프레임 수·시퀀스·
앵커를 명시해 기존의 고정16프레임 가정을 제거한다. Retina 고해상도 창 버퍼 비용은
상세 스프라이트 캐시와 별도로 보고한다.

같은 기기·크기·배율에서 변경 전후의 대기/수면 CPU, 연속 교감 시 CPU, RSS,
품종 전환 후 메모리 회수와 응답 지연을 비교한다. 대기 중 상시 60fps 타이머나
전체 품종 프레임 상주를 추가하지 않고, 변경된 프레임과 예약된 다음 동작만 그린다.

## 3. macOS Control+Shift+V 전환

- 새 기본값과 첫 실행 안내를 `⌃⇧V`/Control+Shift+V로 맞춘다. Command(⌘)와 구분한다.
- 기존 저장값이 이전 기본 Cmd+Shift+V와 같은 경우 한 번만 이관한다.
- 다른 사용자 지정 조합은 보존한다. 구형 설정은 “기본/사용자 지정” 출처가 없어
  이전 기본과 같은 값을 사용자가 선택했는지 구분할 수 없으므로 이 이관 규칙을 알린다.
- 설정 스키마/기본값 출처를 추가해 이후 업데이트가 매번 사용자 선택을 덮어쓰지 않게 한다.
- 메뉴·도움말·툴팁·첫 실행 힌트·키보드 조합 표시·프리셋 순서를 함께 갱신한다.
- 충돌 시 알려주고 대체 진입을 유지한다. 이전 Command 조합으로 조용히 돌아가지 않는다.
- 변경 대상은 전역 패널 열기다. 앱 안의 표준 Cmd+C/V와 다른 편집 명령은 유지한다.
- 한글 IME, 좌/우 Control·Shift, 키를 길게 누르기, 재시작·재등록·충돌을 확인한다.
- 전역 단축키 등록에 입력 감시 권한을 요구하지 않는 경로를 우선한다. 자동 붙여넣기·
  커서 보조 위치 확인에 필요한 별도 접근성 권한까지 없어졌다고 안내하지 않는다.

## 구현 순서와 완료 기준

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 확정된 통계·XP 비활성화, 카운터/활동 시간/통계 UI 제거 | 임의 타이핑·클릭·스크롤 및 복사로 사용량/성장 통계가 갱신되지 않음 |
| 2 | OS 등록형 단축키, Mac 기본값·저장값 이관 | 전체 입력 리스너 없이 각 OS 패널 열기; macOS ⌃⇧V 정상 동작 |
| 3 | 로컬 클릭 판정과 모션 상태/우선순위 | 드래그·패널 클릭 오인 없음; 연타·수면·정지·숨김에서 일관된 응답 |
| 4 | 대표4종(랙돌·샴·봄베이·브리티시) 모션 검수 후12종 확장 | 기존 품종 외형을 유지한 전용 교감; 사냥 동작과 구별 |
| 5 | 모든 OS 실사용·성능·권한 안내·테스트 앱 | Retina 포함 좌표 검증, 기존 기록 보존, 키/마우스 감시 제거 확인 |

검증에는 실제 일반 입력 후 상태 파일·XP 불변 확인, 전역 훅 미설치 감사,
권한 거절/단축키 충돌/설정 이관, 실제 단축키와 IME, 단일 클릭/드래그/패널/투명
영역/연타/수면/복사 동시성, 12종·3크기·1배/2배, 캡처 정지·숨김을 포함한다.
기존 CI의 통계/XP 카운터 의존 성공 판정은 실제 클립 저장·선택·기동 검증으로 바꾼다.
렌더링 프리뷰와 실제 OS 조작/권한 검증을 구분해 보고하며, CI만으로 접근성 승인과
모든 GUI 동작까지 검증했다고 하지 않는다.

보안 거부감의 추가 사각지대로 macOS의 공증 전 앱 실행 경고와 GitHub 로그인·
중첩 ZIP 다운로드도 남아 있다. 입력 감시 제거와 배포 서명/공증은 별개이며,
정식 배포 단계에서 다운로드 동선·서명/공증을 별도로 검토한다.

## 후속 검수 항목

1. 과거 통계/XP를 다음 정상 저장에서 제외하는 마이그레이션 검증과 기능 데이터 보존.
2. OS 등록형 단축키의 지원 범위·충돌·권한 실제 검증.
3. 교감 전용 포즈의 시각 검수. 대표4종부터 비교한다.

이 문서는 계획이며, 통계 삭제·단축키 변경·모션 구현은 아직 실행하지 않았다.
별도 설계 검토에서도 구현 계획 수립을 막는 중대한 미결정 사항은 발견되지 않았다.
