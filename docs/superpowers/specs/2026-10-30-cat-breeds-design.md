# 고양이 종류 확장 기획안

2026-10-30 · 사용자 승인 설계

추가 구현 지시: 12종을 실제 앱에 적용한다. 키·마우스 입력에 반응하는
활동 연출·쓰다듬기·기상·탭 소리는 제거한다. 아래 초기 제안의 활동 반응보다
이 지시가 우선한다. 최종 제품 동작은 [고양이 동료](../../specs/cat-companions.md)를 따른다.

## 확정한 방향

- 액세서리를 폐기하고 품종의 외형과 행동이 다른 캐릭터를 선택한다.
- 사용자가 지정한 11유형에 기존 랙돌을 더해 총 12캐릭터를 완성한다.
- 사용자가 확인한 정책: 처음부터 자유 선택. 기존 레벨·XP·통계는 유지한다.
- 기본 화풍은 극장판 2D 애니메이션풍의 단순한 명암과 깨끗한 외곽선이다.
- 고유한 실루엣, 기본 자세, 모션, 표정을 모두 설계한다. 색상만 바꾸지 않는다.
- 상시 표시되는 한 마리를 기준으로 성능을 설계한다.

턱시도는 품종이 아닌 검정·흰색 털무늬다. 선택 화면의 상위 명칭은
**고양이 종류**로 하고, 설명에 품종 또는 털무늬 유형을 구분한다.
최종 구성은 품종 11개와 털무늬 캐릭터 1개다.

## 실제 외형과 창작 설정을 구분하는 기준

아래 외형은 일반적으로 알려진 품종 특징을 정리한 것이다. 같은 품종에도
여러 털색·눈색·체형 차이가 있으며, 표의 배색은 첫 캐릭터 시안을 위한
대표 외형 선택이다. 성격·행동은 실제 품종 전체를 단정하는 설명이 아니라
앱을 위한 창작 캐릭터 설정이다. 턱시도 무늬로 성격을 추정하지 않는다.

| 종류 | 외형에서 반드시 살릴 특징 | 첫 시안의 배색·눈 |
| --- | --- | --- |
| 랙돌 | 풍성한 중장모, 크고 부드러운 체형, 푸른 눈. 현재 선택한 바이컬러 얼굴의 흰 V 유지 | 크림·씰 바이컬러, 파란 눈 |
| 버만(Birman) | 포인트 배색, 푸른 눈, 네 발끝의 뚜렷한 흰 장갑. 현재 랙돌의 넓은 흰 얼굴 V와 구별 | 씰 포인트·흰 발끝, 진한 파란 눈 |
| 샴(Siamese) | 가는 긴 몸과 다리, 짧은 털, 큰 귀와 쐐기형 얼굴, 포인트 배색과 푸른 눈 | 씰 포인트, 아몬드형 파란 눈 |
| 봄베이(Bombay) | 매끈한 검정 단모, 둥근 머리와 탄탄한 체형, 금색·구리색 계열 눈 | 차콜로 명암을 구분한 검정, 구리빛 눈 |
| 라가머핀(RagaMuffin) | 크고 포근한 체형, 풍성한 중장모, 넓은 얼굴과 호두형 눈. 랙돌의 포인트 무늬를 그대로 재사용하지 않음 | 밝은 브라운 태비·화이트, 황록색 눈 |
| 페르시안(Persian) | 둥근 얼굴, 짧은 코와 작은 귀, 긴 털, 묵직하고 짧은 몸. 얼굴의 납작함은 과장하지 않음 | 크림 장모, 구리빛 눈 |
| 터키시 앙고라(Turkish Angora) | 가는 우아한 몸, 큰 귀, 실키한 털과 길고 풍성한 꼬리 | 흰 털·녹색 눈을 첫 시안으로 선택. 흰색·오드아이가 모든 개체의 필수 특징은 아님 |
| 아메리칸 컬(American Curl) | 뒤쪽으로 말린 귀. 귀가 앞으로 접히는 형태와 구분. 중간 체형과 유연한 꼬리 | 브라운 태비 중장모, 호박색 눈 |
| 먼치킨(Munchkin) | 짧은 다리와 정상적인 크기의 몸·머리. 몸 전체를 작은 고양이로 축소하지 않음 | 치즈 태비 단모, 호박색 눈 |
| 브리티시 쇼트헤어(British Shorthair) | 둥근 볼과 머리, 묵직한 몸, 조밀한 짧은 털, 두툼하고 끝이 둥근 꼬리 | 대표적인 블루 단모, 구리빛 눈 |
| 러시안 블루(Russian Blue) | 은빛이 도는 청회색 단모, 녹색 눈, 가는 몸과 쐐기형 얼굴. 브리티시보다 볼과 몸을 날렵하게 | 실버 블루, 녹색 눈 |
| 턱시도(Tuxedo) | 검정·흰색 털무늬. 품종 고유의 체형은 없으므로 이 캐릭터의 체형을 별도로 선택 | 검정 몸·흰 가슴과 양말, 황록색 눈의 길쭉한 단모 개체 |

품종협회별 인정 범위는 다르므로 하나의 협회에 모두 등록되었다고 표현하지
않는다. 예를 들어 먼치킨의 인정 여부는 협회에 따라 다르다. 원화 검수 시
참고할 공식 자료는 [CFA 품종 소개](https://cfa.org/breeds/)와
[TICA 품종 소개](https://tica.org/breeds/)다. 현재 환경에서 이 협회 사이트에
대한 직접 접근은 허용되지 않아 최신 표준 원문을 실시간 대조한 결과로
표현하지 않는다. 제작 전 품종별 정면·측면 레퍼런스를 대조하는 검수 단계를 둔다.

## 캐릭터별 자세·표정·동작

아래의 성격은 모두 창작 설정이다. 모든 캐릭터는 같은 기능 결과를 전달하되
같은 그림과 타이밍을 재색칠해 사용하지 않는다.

| 종류 | 캐릭터 설정·기본 자세 | 표정 차별화 | 대표 복사 반응 | 수면 실루엣 |
| --- | --- | --- | --- | --- |
| 랙돌 | 느긋한 사냥꾼. 낮게 엎드려 앞발을 모음 | 느긋한 둥근 눈 → 진지하게 집중 → 만족한 눈감음 | 시선 고정 → 몸 낮춤 → 앞발로 확보 | 턱을 앞발에 내려놓은 낮은 솜뭉치 |
| 버만 | 단정한 관찰자. 흰 앞발을 나란히 세워 앉음 | 조용한 호기심과 작은 갸웃 → 부드러운 깜빡임 | 고개를 기울이고 두 흰 앞발 사이로 받음 | 발끝을 모은 채 고개만 옆으로 기울임 |
| 샴 | 참견 많은 감독. 목을 세우고 긴 꼬리 끝을 굽힘 | 아몬드형 눈과 큰 귀의 주의 전환, 작은 입 모양 | 귀부터 반응 → 목을 쭉 뻗어 재빠르게 받음 | 긴 몸을 접고 앞발과 꼬리를 길게 말아 둠 |
| 봄베이 | 조용한 잠복 전문가. 낮고 탄탄한 웅크림 | 구리빛 눈의 시선만 빠르게 이동, 작은 만족 표정 | 눈으로 추적 → 짧고 정확한 한 발 낚아채기 | 차콜 명암으로 읽히는 단단한 둥근 웅크림 |
| 라가머핀 | 포근한 수집가. 둥글게 앉아 앞발을 안쪽으로 모음 | 넓은 볼과 호두형 눈이 함께 부드러워짐 | 두 앞발로 품듯 끌어안고 만족 | 옆으로 기대어 털 속에 턱을 묻음 |
| 페르시안 | 여유로운 감식가. 가슴을 세운 둥근 식빵 | 반쯤 감은 눈 → 잠깐 반짝임 → 느린 눈감음 | 한 박자 관찰 → 작은 고개 움직임으로 받음 | 풍성한 가슴털 위로 고개를 내려놓음 |
| 터키시 앙고라 | 우아하지만 허당인 곡예사. 긴 앞발을 모으고 앉음 | 태연함 → 짧은 놀람 → 다시 태연한 얼굴 | 앞발로 가볍게 띄운 뒤 즉시 받음. 놓쳐 사라지는 연출은 사용하지 않음 | 가느다란 몸을 말고 긴 꼬리가 외곽을 감쌈 |
| 아메리칸 컬 | 호기심 탐색가. 고개를 조금 기울인 앉은 자세 | 눈과 고개의 갸웃, 말린 귀의 작은 방향 전환 | 앞발로 톡 확인 → 코를 가까이 → 받음 | 말린 귀가 보이도록 고개를 옆으로 기울임 |
| 먼치킨 | 성급한 수집가. 짧은 앞다리가 드러나는 낮은 선 자세 | 또렷한 호기심 → 빠른 기대 → 환한 만족 | 짧은 앞발로 두 번 톡톡하며 확보 | 몸을 옆으로 길게 두고 짧은 앞발을 드러냄 |
| 브리티시 쇼트헤어 | 태연한 실무자. 반듯하고 둥글게 앉음 | 둥근 눈의 미세한 변화와 짧은 깜빡임 | 몸은 거의 그대로, 한 발로 받아 담담하게 먹음 | 둥근 볼과 두꺼운 꼬리가 만드는 단정한 식빵 |
| 러시안 블루 | 신중한 기록 담당. 가는 앞발을 정갈하게 모음 | 녹색 눈으로 확인 → 작은 만족 미소 | 잠깐 확인한 뒤 부드럽고 정확하게 당겨 받음 | 가는 앞발을 접고 고개를 살짝 낮춤 |
| 턱시도 무늬 | 능청스러운 집사. 한 앞발을 살짝 들고 느슨하게 앉음 | 무심한 반쯤 감긴 눈 → 순간 집중 → 모른 척 | 시선은 무심하게 두고 앞발로 슬쩍 확보 | 흰 앞발 하나로 눈을 가리고 잠듦 |

## 품종이 실제로 구분되는 제작 규칙

1. 모든 캐릭터는 실루엣·기본 자세·대표 반응의 세 축이 달라야 한다.
2. 같은 품종 안에서는 얼굴 무늬·눈 색·몸 비율과 발 위치가 프레임마다 유지된다.
3. 공통 화풍은 유지하되, 큰 둥근 얼굴 하나를 12번 재사용하지 않는다.
4. 아메리칸 컬의 귀를 펴거나 앞으로 접는 동작은 사용하지 않는다.
5. 먼치킨의 짧은 다리는 외형 특징으로 표현하고, 이동 실패나 무능함의 개그로 사용하지 않는다.
6. 검정 털은 차콜 색면과 제한된 밝은 윤곽으로 읽히게 하고, 어두운 바탕에서 검수한다.
7. 랙돌·버만·라가머핀은 얼굴 무늬·발끝·체형·자세를 함께 비교한다.
8. 브리티시·러시안 블루는 털색 외에도 볼·눈색·다리·몸 비율이 달라야 한다.
9. 생선을 먹는 애니메이션은 기능 성공의 보조 표현이다. 실패로 읽히는 놓침·분실 연출을 피한다.
10. 캐릭터를 돋보이게 하려고 창 이동·포커스 획득·지속적인 큰 동작·자동 대사를 추가하지 않는다.

## 공통 이벤트와 개별 모션

공통 이벤트는 대기, 활동 반응, 복사 수집, 쓰다듬기, 수면 진입·기상,
레벨업이다. 수집 일시정지 표시는 캐릭터의 감정과 별개의 기능 상태로 유지한다.

- 종류마다 프레임 순서·유지 시간·귀/눈/입/앞발의 연기를 다르게 설계한다.
- 기본 캐릭터당 16~24개의 고유 프레임을 목표로 한다. 복사 반응은 약 12포즈를
  시작점으로 삼고, 종류별 전체 재생 시간은 대략 0.8~1.2초 안에서 조정한다.
- 품종마다 별도의 모션 정의를 둔다. 모든 품종에 동일한 프레임 번호나
  동일한 눈·입 좌표를 강제로 적용하지 않는다.
- 저장과 기능 피드백은 즉시 처리하고, 느긋한 캐릭터도 첫 인지 반응은 늦추지 않는다.
- 눈 깜빡임·수면·회복에서는 같은 캐릭터 안의 포즈를 재사용할 수 있다.
- 연속 복사는 모든 수집 데이터를 처리하면서 시각적 대기만 하나로 제한한다.

## 선택 UX와 기존 데이터 전환

1. Windows 트레이와 고양이 우클릭에서 **고양이 선택**을 연다.
2. 12종의 이름·정지 썸네일·종류 설명을 보여 준다. 실제 외형 정보와 앱 캐릭터
   성격 설명을 구분한다.
3. 선택한 카드에서 평상·복사 반응·수면을 미리 볼 수 있다. 목록 전체를 동시에
   움직이지 않으며, 미리보기는 명시적인 조작으로 시작한다.
4. **함께하기**로 적용한다. 모든 종류는 처음부터 선택 가능하고 언제든 바꿀 수 있다.
5. 변경해도 클립보드 기록·태그·AI 작업대·XP·레벨·통계·설정은 유지된다.
6. 앱 재시작 후 같은 캐릭터가 복원된다. 기본값은 현재 랙돌이다.

현재 액세서리 메뉴·그리기·해금 표와 레벨업 자동 착용을 제거한다. 구버전의
`accessory` 값은 새 캐릭터에 임의로 대응시키지 않는다. 이전 설정을 안전하게
읽고 무시하며 새 `cat_kind`가 없으면 랙돌을 선택한다. 종류는 배열 순번이 아닌
`ragdoll`, `birman`, `siamese` 같은 고정 ID로 저장한다. 턱시도 ID도 같은 목록의
캐릭터 ID로 취급하되 분류 정보는 털무늬로 기록한다.

기존 레벨·누적 XP는 보존한다. 레벨업은 짧은 축하와 통계 진행만 표현하며,
고양이를 자동 교체하거나 특정 종류를 상위 보상으로 취급하지 않는다.
통계 초기화도 사용자가 선택한 고양이를 바꾸지 않는 방향을 권한다.

## 구현 구조 제안

세 접근을 비교한다.

| 접근 | 장단점 | 판단 |
| --- | --- | --- |
| 같은 몸과 모션에 배색만 변경 | 제작은 빠르지만 체형·귀·성격 차별화 불가 | 목표와 맞지 않음 |
| 품종별 이미지·모션 정의 + 공통 재생기 | 외형과 행동은 독립 제작하고 기능·성능 정책은 공유 가능 | 권장 |
| 품종별 별도 렌더러·시뮬레이션 | 자유도는 높지만 종류마다 기능 동작과 버그가 갈라짐 | 초기 범위에서는 과도함 |

권장안은 품종 목록과 표시 이름, 외형 메타데이터, 정지 썸네일, 투명 프레임,
모션 순서·시간, 입·발·발바닥 기준점 정보를 캐릭터 단위로 묶는 구조다.
기존 `hunter_art`·`hunter_motion`의 랙돌 전용 정의를 이 구조로 옮기고,
`Pet`은 선택한 캐릭터와 공통 이벤트를 조율한다. OS API는 기존 플랫폼 경계에 둔다.

특히 현재의 전역 `OnceLock` 캐시를 종류마다 하나씩 만드는 방식은 피한다.
선택한 캐릭터가 소유하는 교체 가능한 캐시로 바꿔야 이전 캐시를 해제할 수 있다.
모션에 쓰는 입 위치는 코 위치에서 일괄 추정하지 않고 프레임별로 정의한다.

## 상시 실행 성능

- 선택한 한 마리의 상세 프레임만 유지한다. 12종 상세 프레임을 함께 해독하지 않는다.
- 현재 240×180 RGBA 기준 16프레임은 2.64MiB, 24프레임은 약 3.96MiB다.
  순수 상세 프레임 캐시는 캐릭터당 4MiB 미만을 시작 제약으로 유지한다.
- 96×96 RGBA 정지 썸네일 12장은 약 0.42MiB다. 선택 화면에서만 별도로 사용한다.
- PNG 해독과 임시 전환 메모리는 위 캐시 수치와 별도로 측정한다.
- 선택 변경 때는 해독 작업을 하나로 제한하고 마지막 선택만 적용한다. 이전
  고양이는 새 자산 준비가 끝날 때까지 표시해 깜박임을 막는다.
- 프레임을 미리 일정 크기·발 위치로 정규화하는 제작 단계를 둔다. 원화 전체를
  앱에 그대로 포함하지 않고 실제 표시 크기에 맞는 배포용 아틀라스로 묶는다.
- 모든 자산은 앱에 포함하며 런타임 다운로드나 추가 네트워크 기능을 만들지 않는다.
- 대기·수면 정지 렌더링, 이벤트 때만 재생, 클립보드 처리와 화면 갱신 분리를 유지한다.
- 품종을 늘리면 배포 파일은 커진다. 한 마리만 해독하면 실행 메모리는 전체 품종 수와
  비례해 늘지 않도록 만들 수 있다. 실제 RSS와 전환 중 최고값은 릴리스 빌드로 확인한다.

## 제작 순서와 통과 기준

최종 범위는 12종 전체이며 아래 구분은 제작·검수 묶음이다.

**1단계 — 외형 설계:** 12종을 같은 화풍의 정지 시안으로 먼저 비교한다.
각 종은 정면/기본 자세, 측면 체형, 사냥, 수면을 준비한다. 사진 레퍼런스의
특징 체크리스트와 배경 밝음·어두움, 실제 작은 크기를 함께 확인한다.

**2단계 — 대표 4종 구현 검증:** 기존 랙돌 + 샴 + 봄베이 + 브리티시 쇼트헤어.
풍성한 장모·가는 큰귀·검정 털·둥근 단모라는 차이로 공통 재생기와 선택 UI를 검증한다.

**3단계 — 형태 확장 4종:** 페르시안 + 터키시 앙고라 + 아메리칸 컬 + 먼치킨.
얼굴·털 흐름·귀·다리 길이가 달라도 프레임과 입·발 위치가 안정적인지 확인한다.

**4단계 — 유사 외형 정밀화 4종:** 버만 + 라가머핀 + 러시안 블루 + 턱시도.
앞선 캐릭터와의 색 없는 실루엣 비교, 얼굴·발·눈색과 동작 차이를 집중 검수한다.

**5단계 — 전체 실사용:** Windows에서 트레이/우클릭 선택, 재시작 복원,
기존 상태 마이그레이션, 연속 복사, 정지·재개, 숨김·복원, 패널·작업대,
크기 변경과 모든 캐릭터의 복사/수면/기상 동작을 실제 사용한다. 발견한 문제는
바로 고치고 영향 흐름을 재검증한다. Linux 등에서 대체 실행한 부분은 구분한다.

완료 기준:

- 이름을 가려도 평상·수면 실루엣에서 종류 간 차이를 읽을 수 있다.
- 비슷한 종류는 털색을 빼도 체형·귀·자세 중 하나 이상으로 구분된다.
- 품종별 기본 자세·복사 반응·표정 변화가 각각 정리되어 실제로 구현된다.
- 흰 발끝, 뒤로 말린 귀, 눈색 등 핵심 특징이 모든 프레임에서 유지된다.
- 크기 3단계와 밝고 어두운 바탕에서 얼굴과 눈·귀가 읽힌다.
- 교체해도 기록과 레벨이 보존되고, 실패·빠른 연속 선택·알 수 없는 저장 ID가
  앱을 중단시키거나 임의의 캐릭터를 선택하지 않는다.
- 12종을 순서대로 반복 교체해도 상세 캐시가 종류 수만큼 쌓이지 않는다.
- 현재 v2.4.0 대비 대기 CPU 회귀가 없고, 선택 지연·메모리·최대 해독 메모리를 보고한다.
- 각 종의 실제 앱 화면과 모션 GIF를 함께 보고한다.

이번 산출물은 기획이며 제품 코드·릴리스에는 변경을 적용하지 않았다.
