# 클립보드 태그와 이미지 — Windows

## 사용 방법

- 항목의 `…`를 누른 뒤 `#` 버튼으로 태그를 편집한다. 키보드로는 항목을
  선택하고 `Ctrl+T`를 누른다. 태그는 쉼표나 공백으로 구분한다.
- `Enter`로 저장하고 `Esc`로 취소한다. `Ctrl+A` 후 새 내용을 입력하면 전체를
  바꿀 수 있고, `Ctrl+A` → `Backspace` → `Enter`로 모든 태그를 제거한다.
- 항목당 최대 8개, 태그당 최대 24자다. 중복 태그는 대소문자 구분 없이 합친다.
- 검색창에 `#업무`처럼 입력하면 그 태그를 가진 항목만 표시한다.
  `#태그`는 태그 전체가 일치해야 하며 영어 대소문자는 구분하지 않는다.
  `#업무 #참고`는 두 태그를 모두 가진 항목, `#업무 보고서`는 업무 태그와
  보고서 검색어가 모두 일치하는 항목을 표시한다. 일반 검색어는 내용·앱 이름·
  태그의 일부에도 일치하며, 기존 앱별 필터와 함께 사용할 수 있다.
  예를 들어 `work`는 `Work` 태그를 찾고 `#wor`는 찾지 않는다.
- Windows 네이티브 앱에서 캡처 도구·그림판·브라우저 등의 이미지를 복사하면
  고양이가 반응하고 히스토리에 썸네일과 이미지 크기가 나타난다.
- 이미지 항목을 클릭하거나 `Enter`로 선택하면 이미지로 다시 복사한다.
  핫키 플라이아웃에서는 원래 앱으로 붙여넣고, 가운데 클릭 패널에서는
  기존의 ‘선택 시 붙여넣기’ 설정을 따른다. 빠른 복사도 사용할 수 있다.
- 이미지에도 태그·고정·검색·삭제·복구를 적용할 수 있다.
  이미지에는 ‘텍스트로 붙여넣기’를 제공하지 않는다.

## 지원 범위

PNG 및 비압축 24/32비트 DIB, 32비트 bitfields를 지원한다. 텍스트와 이미지가
동시에 있으면 지원되는 이미지를 우선 저장한다. 파일 탐색기의 ‘파일 복사’는
이미지 픽셀 복사와 다르므로 대상이 아니다. OCR, GIF 애니메이션, 이미지 편집,
macOS·Linux·Windows portable 이미지 캡처는 포함하지 않는다.

PNG는 투명도를 유지한다. PNG를 지원하지 않는 붙여넣기 앱을 위해 흰 배경으로
합성한 DIB도 함께 쓴다. 저장 한도는 이미지당 16,777,216픽셀 및 PNG 16MiB,
이미지 히스토리와 세션 복구 데이터 합계는 base64 기준 64MiB다.
한도를 넘거나 지원하지 않는 이미지는 저장하지 않는다.
모든 데이터는 기존 `clips.json`에 로컬 저장한다.

## Windows 수동 확인

1. 클립보드에 텍스트·HTML/RTF·스크린샷·사진을 차례로 복사한다. 텍스트 서식과
   이미지 썸네일이 맞고 각각 새 복사로 한 번만 집계되는지 확인한다.
2. 텍스트와 이미지에 한국어·영어 태그를 붙이고 검색한다. 편집 저장·취소·전체
   삭제, 앱별 필터와의 조합, 재시작 후 태그·이미지 복원을 확인한다.
3. 그림판 또는 이미지 붙여넣기가 가능한 문서 앱에 포커스를 둔 뒤
   `Win+Shift+V` → 이미지 선택을 마우스·Enter·Ctrl+숫자로 각각 확인한다.
   투명 PNG와 DIB-only 스크린샷을 모두 사용한다.
4. 가운데 클릭 패널에서도 이미지 복사와 ‘선택 시 붙여넣기’ 켜기/끄기를 확인한다.
   자동 닫기 켜기/끄기, 빠르게 선택해 Shift가 남는 경우도 확인한다.
5. 다시 복사한 이미지가 새 히스토리·XP를 만들지 않고, 다른 앱에서 같은 이미지를
   새로 복사하면 기존 항목을 갱신하는지 확인한다. 일시정지 중에는 수집하지 않는다.
6. 이미지 고정·삭제·복구와 재시작을 확인한다. 테스트는 합성 데이터로 수행한다.

Windows 전용 자동 검사는 `native_clipboard_roundtrips_text_png_and_dib`이며,
`cargo test --locked --release`에서 실행된다. Linux의 Windows 교차 검사는
테스트를 컴파일만 하므로 위 수동 확인을 대체하지 않는다.
