# 고양이 캐릭터 업그레이드 — 7개 방향 (개별 기획·구현 문서)

ClipCat 고양이 캐릭터를 업그레이드하기 위한 7개 방향을 **방향성별 개별 MD 문서**로
정리한 묶음이다. 형태·톤앤매너는 그대로 두고, 카카오톡 인기 이모티콘의 성공 공식을
빌려 "엉뚱 + 익살 + 볼매" 감정을 설계한다. 7개 방향은 모두 적대적 검증으로 수렴한
확정 캐릭터 정체성을 척추로 공유한다.

> **확정 캐릭터 정체성**: *"생선 본위제 먹보 고양이의 속마음 (+ id-미러)"*
> — 복사한 텍스트를 생선으로 벌어먹는 게으른 먹보 순둥이 고양이가 세상 모든 것을 생선으로
> 환산해 이야기한다(불변 본캐 = 정체성). 무드는 *정체성이 아니라 텍스처*로, 로컬 상태가
> "생선에 대해 뭐라 하는지"만 바꾼다(집중→독설, 유휴→병맛, 야근→다정, 직접 조작→츤데레).
> 일부 라인은 생선 은유를 걷어내고 사용자 속마음을 1인칭으로 대신 말한다(**id-미러**:
> "나 대신 빡쳐줄게", "오늘은 그냥 눕자, 생선은 내일"). 성공한 카카오톡 이모티콘 역산
> 루브릭에서 컨셉 품질 스코프 **97/100**(앵커 잔망루피·망그러진곰 = 96).

## 의존 관계 & 권장 착수 순서

- **빌딩블록**: 방향 2(보이스/표정 엔진)·3(모션)
- **그 위에**: 방향 5(보이스 운영)·6(부캐 묶음)·7(관계)
- **가로로 받침**: 방향 1(코스메틱 자산)·4(수집 메타)

→ 권장 착수: **2·3(★최우선) → 5 → 1 → 4 → 6 → 7**

## 공통 가드레일 (AGENTS.md 골든룰)

- **프라이버시**: 입력 후킹은 카운터(KEYS/CLICKS/WHEEL)만. **로컬 활동 상태만** 기능 구동
  (키 내용·창 제목·타이밍 절대 미사용). 네트워크는 `update.rs`(GitHub 릴리스 체크) 외 금지.
  죄책감/방치형·사용 추적 리텐션·결제/가챠/스트릭/리더보드 **전부 배제**.
- **에셋**: 전부 코드로 그리는 벡터아트(tiny-skia). 번들 이미지 금지.
- **코어 OS-비종속**, 모든 문구 `i18n`(영/한), 두 백엔드(native Win32 / portable) 인터랙션 패리티.
- 신규 heavy dependency는 ADR 없이는 금지.

> 산출 경위: 7개 방향마다 개별 Sub-Agent를 병렬 실행(맥락 보존 — 정체성·코드맵·가드레일 전달)
> 하여 코드 기반으로 구현 가능성을 실측한 결과를 방향별 문서로 정리했다.
