# 구현 요청 — 방향 3: 살아있는 고양이 ★최우선

공통 규칙(역할·정체성·제약·검증·워크플로)은 [README](README.md) 참조.

**스펙**: `docs/specs/directions/03-living-cat.md` — 모션·행동 디테일. 게으른 먹보 본캐(idle일수록 늘어짐).

## 범위
1. 아이들 행동 풀(소형 상태기계): 그루밍/기지개/하품/두리번/꼬리 쫓기, idle·sleep 낮을 때 수 초 ±랜덤(frame/rng 재사용).
2. 보조동작: 귀 씰룩·수염 떨림(hover)·호흡 bob 강화 — phase+sin.
3. 팔로스루/오버랩: 몸 squash 후 꼬리·귀 15~25% 지연(1차 lerp).
4. 클릭/더블클릭 확장: 쓰다듬기 wiggle + 하트, 연타 점증 반응.
5. 이스터에그(황금 생선): on_copy에서 rand_f 저확률 게이트로 골드 badge + 과장 환희(기존 fish/파티클 재사용).
6. 로컬 일주기: `today_string` 패턴의 `local_hour()` leaf(시만) 추가, 밤엔 더 졸리게 + 은은한 틴트 1장.

## 권장 1차 PR
코어만으로 자동 패리티인 **#1·#2·#3**. #5·#6은 후속. #4의 **새 입력 제스처(hold-to-pet 등)는 양 백엔드 동일 임계 구현 필요 → 도입 전 질문**.

## 이 방향 특이 주의
- **CPU는 release에서만 측정**(디버그 ~10× 느림). 깊은 수면(sleep>0.9) 프레임 스킵 보존, idle 행동은 sleep 낮을 때만.
- 행동·연출 선택은 감정 float·rng·로컬 시각만 — clips/source 미사용.
