# 구현 작업 요청 — 방향 2: 감정·표정 설계 (엉뚱 + 익살 + 볼매) ★최우선

## 역할
너는 ClipCat(러스트 초경량 클립보드 매니저 데스크탑 펫) 저장소에서 작업하는 시니어 러스트
엔지니어다. 아래 기획 문서를 바탕으로 고양이의 감정·표정·말풍선 엔진을 실제 코드로 구현한다.

## 먼저 읽을 것 (반드시 정독)
- `AGENTS.md` (골든룰·아키텍처·검증 절차 — 단일 진실 공급원)
- `docs/specs/directions/README.md` (7개 방향 개요 + 확정 캐릭터 정체성)
- `docs/specs/directions/02-emotion-design.md` ← 이번 작업 핵심(터치할 파일·함수 file:line, 재사용 패턴)
새 코드 전에 기존 함수(draw_face, set_toast/draw_bubble, level_up, 감정 float, rand_f)를 먼저 재사용하라.

## 확정 캐릭터 정체성 (척추 — 흔들지 말 것)
"생선 본위제 먹보 고양이의 속마음 (+ id-미러)". 본캐 불변, 무드는 정체성이 아니라 '텍스처'로 로컬
상태가 "생선에 대해 뭐라 하는지"만 바꾼다(집중→독설, 유휴→병맛, 심야→다정, 직접 조작→츤데레).
일부 라인은 생선 은유를 걷고 사용자 속마음을 1인칭으로 대신 말한다(id-미러: "나 대신 빡쳐줄게").
이 방향은 표정/감정 float/말풍선 한 줄의 **메커니즘** 담당(라인 운영·작명=방향5, 부캐=방향6).

## 이번 작업 범위
1. [#3] 무드 텍스처 + id-미러 말풍선 라인 엔진: 로컬 신호(rate/excite=집중, sleep/idle=유휴, 로컬
   시각=심야, pet/click=직접조작)로 무드 선택 → set_toast/draw_bubble 한 줄. 매번 텍스처 풀 vs id-미러
   풀 가중 추첨(id-미러 ~25%). 라인은 전부 i18n EN+KO. 쿨다운으로 절제, 직전 인덱스 1개 기억.
2. [#1] 무표정/멍 베이스라인: 감정 float 모두 낮을 때 점눈+일자입. `Scene.blank`는 파생값(신규 상태 변수 X).
3. [#2] 갭모에 서프라이즈 표정 풀(4~6종, 레어 가중 랜덤): draw_face 분기(enum 추가 없이 u8 인덱스), ±랜덤 타이밍.
4. [#4] 활동 반응 감정 강화: 빠른 입력→헥헥/땀(excite), 유휴→반쯤 감긴 눈 droop(sleep).
5. [#5] kama-muta 모먼트: 레벨업/마일스톤에 blush boost + 하트 버스트 + id-미러 한 줄.
6. [#6] 표정-악세사리 연동: 해금/착용 직후 윙크 + 츤데레 라인 1회.

### 권장 1차 PR
가장 가치 큰 **#3(라인 엔진) + #1·#2(무표정/갭모에 표정 = 볼매 핵심)**. #4·#5·#6은 후속 커밋/PR.

## 반드시 지킬 제약 (위반 시 작업 무효)
- 프라이버시: 입력 후킹은 카운터만. 키 내용·창 제목·타이밍 읽기/저장/로그/전송 금지. 라인/표정
  선택은 오직 로컬 활동 상태(카운터 파생 float, 로컬 시각, 레벨, 일시정지)만. 새 네트워크 금지(허용은 `update.rs`뿐).
- 에셋은 전부 tiny-skia 코드 드로잉. 번들 이미지·새 heavy dependency 금지(필요 시 ADR 먼저 제안).
- 코어 OS-비종속(pet.rs/render.rs/i18n.rs). 두 백엔드 패리티(코어에만 두면 자동 동등).
- 모든 사용자 문구 i18n(영/한 동시). 결제/가챠/스트릭/방치 죄책감 금지.
- 반복 피로 방지: 멘트·서프라이즈 표정은 rand_f + ±랜덤 타이밍으로 저빈도·예측 불가.

## 완료·검증 기준 (전부 통과해야 done)
1. `cargo build --release` / `cargo clippy --release` (+ `--features portable`) — 경고 0.
2. `cargo test --release` — 신규 라인 선택·표정 분기에 결정적 단위 테스트. i18n 패리티
   (`every_message_has_both_translations`) + 신규 라인 풀 전수(무드별 EN/KO 비어있지 않음) 테스트.
3. `cargo run --release --example preview` — 무드/id-미러/서프라이즈 표정/한글 멘트 PNG 출력, 토스트 폭에 한글이 들어가는지 육안 확인.
4. 프라이버시 셀프 감사: 신규 코드가 clips/키 내용/source 문자열을 분기에 안 쓰는지 PR 설명에 명시.
5. `CHANGELOG.md` `[Unreleased]`에 사용자 관점 한 줄(영문) 추가.
