# 구현 요청 — 방향 2: 감정·표정 설계 (엉뚱+익살+볼매) ★최우선

공통 규칙(역할·정체성·제약·검증·워크플로)은 [README](README.md) 참조.

**스펙**: `docs/specs/directions/02-emotion-design.md` — 이 방향은 표정/감정 float/말풍선의 **메커니즘** 담당(라인 운영·작명=방향5, 부캐=방향6).

## 범위
1. 무드 텍스처 + id-미러 라인 엔진: 로컬 신호(rate/excite=집중, sleep/idle=유휴, 로컬 시각=심야, pet/click=조작)로 무드 선택 → `set_toast`/`draw_bubble`. 매번 텍스처 vs id-미러 가중 추첨(id-미러 ~25%). i18n EN/KO, 쿨다운·직전 인덱스 기억.
2. 무표정/멍 베이스라인: 감정 float 낮을 때 점눈+일자입. `Scene.blank`는 파생값(신규 상태 변수 X).
3. 갭모에 서프라이즈 표정 풀(4~6종, 레어): `draw_face` 분기(enum 없이 u8 인덱스), ±랜덤 타이밍.
4. 활동 반응 강화: 빠른 입력→헥헥/땀(excite), 유휴→반쯤 감긴 눈 droop(sleep).
5. kama-muta: 레벨업/마일스톤 blush boost + 하트 버스트 + id-미러 한 줄.
6. 표정-악세사리 연동: 해금/착용 직후 윙크 + 츤데레 라인 1회.

## 권장 1차 PR
**#1(라인 엔진) + #2·#3(무표정/갭모에 = 볼매 핵심)**. #4·#5·#6은 후속.

## 이 방향 특이 주의
- 라인 풀은 무드별 전수 테스트(EN/KO 비어있지 않음). 반복 피로 방지: rand_f + ±랜덤 타이밍.
- 신규 코드가 clips/키 내용/source를 분기에 안 쓰는지 PR 설명에 명시.
